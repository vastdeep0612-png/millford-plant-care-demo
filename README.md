# DEMO PROJECT

Self-initiated sample. This is not a client website.

## Objective

Show a small one-page business site: a hero, services, a short explanation of the visit, and a contact form that validates in the browser.

The business, Millford Plant Care, is fictional.

## Tech stack

HTML, CSS, and a small script. No build step and no external images.

## Features

- Responsive layout for a wide window, a tablet-width window, and a phone-width window
- Sticky header and a menu button below 800px
- Skip link, visible focus, and labels on every field
- Form checks for name, email, visit type, and message length
- The form does not send or store the message

## Responsive testing

Checked at about 1280px and 390px.

- No sideways scrolling on the page
- The menu opens and closes on a narrow screen
- Empty and short fields show an error
- A complete form shows the confirmation and still does not send anything
- The browser console stays empty

## How to run

Open `index.html` in a browser, or serve this folder and open the index.

GitHub Pages serves the same files.
